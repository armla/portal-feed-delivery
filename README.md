# The Agency Costa Rica — Portal Feed Delivery

This repository is a **public delivery endpoint** for validated XML files consumed by approved listing portals.

It intentionally contains **only generated XML artifacts**. Source code, selection rules, caches, API configuration, credentials, workflow logic, operational documentation, and marketing activity state are maintained in private source repositories.

| Portal | Delivery file |
|---|---|
| Encuentra24 | `encuentra24/encuentra24_feed.xml` |
| JamesEdition Elite | `jamesedition/elite.xml` |
| JamesEdition Portal | `jamesedition/portal.xml` |

Portal URLs are changed only after the automated publication workflow has been validated.
